# ATOM Parfums

Sitio web estático de ATOM Parfums, listo para publicar con GitHub Pages.

## Publicar en GitHub Pages

1. Crea un repositorio público nuevo en GitHub, por ejemplo `atom-parfums`.
2. Sube todos los archivos de esta carpeta al repositorio.
3. En GitHub, abre **Settings → Pages**.
4. En **Build and deployment**, elige **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/(root)`, y guarda.

GitHub mostrará el enlace público, normalmente en el formato `https://tu-usuario.github.io/atom-parfums/`.

Cuando ATOM tenga su dominio propio, se puede conectar desde la misma sección de Pages.
